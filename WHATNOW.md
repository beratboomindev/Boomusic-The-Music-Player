# What Now? — Boomusic Roadmap

Planlanan özellikler ve yol haritası.

## Themes
- Önceden hazır temalar (light / dark / high-contrast / solarized)
- Kullanıcı tema editörü (renk, font, boşluk, köşe yuvarlaklığı)
- Tema paketi formatı (`.boomtheme`)
- Community tema paylaşımı

## Plugins
- Plugin loader mimarisi (güvenli sandbox)
- Eklenti yönetim ekranı (Settings içinde)
- Resmi pluginler:
  - **Last.fm scrobbling**
  - **Discord Rich Presence**
  - **Lyrics** (şarkı sözleri paneli)
  - **Equalizer** (10-band)
  - **Audio visualizer**
- Plugin geliştirici dokümantasyonu

## Spotify Integration
- Spotify hesabı ile giriş (OAuth)
- Kişisel playlist'leri içe aktarma
- Spotify arama (Boomusic içinden)
- "Şarkıyı Spotify'da aç" eylemi (sağ tık menüsü)
- Kütüphaneyi Spotify ile senkron tutma (iki yönlü)
- Ücretsiz tier kısıtı: sadece 30 saniyelik önizleme (Spotify API sınırı)

## Recommended for You
- Dinleme geçmişine dayalı kişisel öneriler
- "Bunu sevenler bunu da sevdi" benzeri algoritmalar
- Zaman dilimi bazlı öneriler (sabah / gece farklı ruh hali)
- Günlük keşif listesi
- Beğen / beğenme geri bildirimi ile öğrenen model
- "Şimdi çalana benzer" butonu
